# Contributing

This is a curation, not a directory. A short section is better than a padded one.

## What belongs here

An entry should help a builder who already shipped to:

- hear a real customer problem,
- write an offer someone will pay for,
- take money,
- or run a local/self-hosted agent that does the repetitive parts of that loop.

## What does not belong

- Another "intro to transformers" course (send those to [awesome-artificial-intelligence](https://github.com/owainlewis/awesome-artificial-intelligence)).
- Unmaintained repos, coming-soon landing pages, or affiliate dumps.
- Items whose only job is to sell inference credits.
- Duplicate entries that do not beat what is already listed.
- Undisclosed self-promotion. If it is yours, say so.

## Entry format

Add at the bottom of the right section:

```md
- [Name](https://example.com/) — One factual sentence on the builder problem it solves.
```

- Title case the name.
- Link the primary source (repo, official site, or book page — not a Medium recap).
- No emojis in entries.
- No "best ever" or "revolutionary" copy.

## PR checklist

- [ ] I read this file.
- [ ] The resource is public and currently usable.
- [ ] It is not already on the list under another name.
- [ ] Description is one sentence and checkable.
- [ ] I disclosed affiliation if I work on it or get paid to mention it.
